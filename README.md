# 컨벤션

## **커밋 컨벤션**

- **커밋 컨벤션**
- 커밋 메시지 장난식 절대 XXX 아래 양식을 꼭 지켜주세요
- **예시 ) ♻️ Refactor: 엔티티 수정 <<<<<<<<<←**
    - ✨ **`Feat`**: 새로운 기능을 추가하는 경우 (Introduce new features.)
    - 🐛 **`Fix`**: 버그를 고친경우 (Fix a bug.)
    - 📝 **`Docs`**: 문서를 수정한 경우 (Add or update documentation.)
    - 🎨 **`Style`**: 코드 포맷 변경, 세미콜론 누락, 코드 수정이 없는경우  (Improve structure / format of the code.)
    - ♻️ **`Refactor`**: 코드 리펙토링 (Refactor code.)
    - ✅ **`Test`**: 테스트 코드. 리펙토링 테스트 코드를 추가했을 때 (Add, update, or pass tests.)
    - ✏️ **`Chore`**: 빌드 업무 수정, 패키지 매니저 수정 등 동작에 영향 없는 코드 (Fix typos.)
    - 💄 **`Design`**: CSS 등 사용자가 UI 디자인을 변경했을 때 (Add or update the UI and style files.)
    - 🚚 **`Rename`**: 파일명(or 폴더명) 을 수정한 경우 (Move or rename resources (e.g.: files, paths, routes).)
    - 🔥 **`Remove`**: 코드(파일) 의 삭제가 있을 때. (Remove code or files.)
    - ⚡️ **`Improve`**: 성능 개선 (Improve performance.)
